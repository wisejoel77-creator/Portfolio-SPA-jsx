SPA PORTFOLIO-JSX

This is a Single Page Application (SPA) built with React and Vite that allows users to view and manage a portfolio of projects.

FEATURES INCLUDE:
- View a list of projects on the landing page
- Add new projects using a form
- View detailed information about each project
- Dynamic UI updates using React state

HOW TO USE THE APP
- Immediately you get into the app you will see an two input boxes.
- The first input box under the title (project title) is where you type in the title of your project.
- The second input box just under the title (project description) is where you type in what your project is all about.
- After filling all the fields you can click the submit button so that your project can be displayed in the project list.
- If you may want to delete your project, you can do so by clicking the "Delete project" button which is located in the project list section. 

NOTE: You cannot submit the project information and name without filling out the two input fields.
